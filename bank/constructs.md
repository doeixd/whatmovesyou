# Construct definition sheets

Phase 0 of [../research/PLAN-06-item-methodology.md](../research/PLAN-06-item-methodology.md). Nothing gets written for a scale until its sheet is signed off.

Status: **draft v0.1** — sheets written, not yet reviewed. Sign-off = 2 reviewers agree the OUT OF SCOPE and BOUNDARY CASES lines are decidable.

---

## A1 · Drive

| | |
|---|---|
| **Definition** | Tendency to initiate activity and to expend effort for reward, absent external demand. |
| **Poles** | Inert ←→ Driven |
| **Facets** | **Exploration** — seeking novelty and information unprompted. **Effort tolerance** — paying a cost for a larger or later reward. |
| **In scope** | Self-initiated projects; persistence past the interesting phase; cost/benefit tradeoffs actually made; unprompted information seeking. |
| **Out of scope** | Conscientiousness (Drive is initiation, not reliability — see A3); Sociality; current energy level (state); achievement outcomes (confounded with opportunity and SES). |
| **Boundary cases** | Works 60h/week under threat of firing → **not** high Drive (external demand). Many projects started, few finished → high Exploration, low Effort tolerance; the facets must separate. Intense drive in one narrow domain → counts, but check overlap with A7. Driven by fear of failure → counts as Drive, and likely co-elevates A2. |
| **Severity** | Mild: takes optional work occasionally. Notable: consistently generates own projects. Extreme: cannot rest; initiates at clear personal cost. |
| **Body link** | Dopamine (reward, effort, exploration) — **strong**. Agonists produce impulse-control disorders; amphetamine raises effort-for-reward. |
| **State sensitivity** | Medium — depression suppresses it markedly. |
| **Visibility** | High. Expect self-informant r ≈ .5–.6. |
| **Confounds** | SES and life stage (a parent of a newborn has no slack); cultural norms around self-promotion. |

## A2 · Threat reactivity

| | |
|---|---|
| **Definition** | How readily and how durably negative emotion is triggered by threat, loss or criticism. |
| **Poles** | Unflappable ←→ Highly reactive |
| **Facets** | **Trigger threshold** — how little it takes. **Persistence** — how long it lasts. **Anticipation** — how much is spent on threats that haven't happened. |
| **In scope** | Rumination after conflict; sensitivity to tone and disapproval; pre-emptive worry; physical tension accompanying worry. |
| **Out of scope** | Current depressive episode (that's the state block); Antagonism's anger (A5 is outward, A2 is inward); sensory sensitivity (A7). |
| **Boundary cases** | Reacts hard but recovers in minutes → high trigger, low persistence; report both. Never reacts but is chronically flat → likely low Drive or depression, not low A2. Anxiety only about one domain (health, money) → counts if pervasive within it. |
| **Severity** | Mild: takes criticism to heart for an hour. Notable: replays conflicts for days. Extreme: anticipated threat governs daily choices. |
| **Body link** | Serotonin 5-HT2A — **moderate**. Cortical 5-HT2A binding ↔ inward neuroticism facets, r ≈ .37, replicated with a second tracer; SSRIs lower neuroticism beyond their effect on depression. |
| **State sensitivity** | **High** — this is the scale most inflated by a current episode. Widen its band and attach a retake caveat. |
| **Visibility** | Low. Expect weak self-informant agreement; much of this is private. |
| **Confounds** | Current life stress; cultures that valorize or suppress emotional expression; gender-differentiated reporting norms. |

## A3 · Restraint

| | |
|---|---|
| **Definition** | Capacity to hold to an intention against a competing immediate pull. |
| **Poles** | Impulsive ←→ Controlled |
| **Facets** | **Cue resistance** — not acting on an available temptation. **Follow-through** — continuing after motivation fades. **Verbal/behavioral brake** — not saying or doing the thing in the moment. |
| **In scope** | Unplanned spending; stopping when intended; finishing dull remainders; regretted speech. |
| **Out of scope** | Drive (A1 is initiation; A3 is inhibition — a person can be high on both); Antagonism (A5 is motive, A3 is control); neatness or planning as aesthetics. |
| **Boundary cases** | Rigidly controlled to the point of inflexibility → very high A3; note the cost, don't treat high as uniformly good. Impulsive only with one substance/activity → counts, flag for the reward-cue gain axis. Poor follow-through from distraction, not pull → likely the ADHD flag (Block C), not low A3 alone. |
| **Severity** | Mild: occasional unplanned purchase. Notable: repeated costly stops-too-late. Extreme: impulses reliably produce damage. |
| **Body link** | Dopamine reward-cue — **strong** (dopamine agonists cause impulse-control disorders); serotonergic constraint — **moderate** (tryptophan depletion raises aggression in the already-prone). |
| **State sensitivity** | Medium. |
| **Visibility** | High for behavioral consequences, low for internal effort. |
| **Confounds** | Income (impulsive spending is visible only with money to spend); access and opportunity. |

## A4 · Sociality

| | |
|---|---|
| **Definition** | Baseline need for, and reward from, closeness with other people. |
| **Poles** | Detached ←→ Connected |
| **Facets** | **Need** — discomfort when contact is absent. **Reward** — pleasure taken from closeness. **Disclosure** — willingness to be known. |
| **In scope** | Response to time alone; seeking others when distressed; depth of disclosure; whether warm contact lifts mood. |
| **Out of scope** | Social *skill* or anxiety (a person can want closeness and fear it — that's A2 plus A4); extraversion-as-stimulation-seeking (A1); number of acquaintances. |
| **Boundary cases** | Wants closeness, avoids it from fear → high A4, high A2; the combination is the finding. Content alone, connects easily when present → moderate A4, not low. Many contacts, no disclosure → low Disclosure facet specifically. Cultural norms about family obligation ≠ personal need. |
| **Severity** | Mild: prefers own company. Notable: weeks alone feel fine. Extreme: closeness is unrewarding or aversive. |
| **Body link** | μ-opioid — **preliminary**. Receptor availability tracks attachment style; lower availability with avoidant attachment. Single research group. |
| **State sensitivity** | Medium-high — depression produces withdrawal that mimics low A4. |
| **Visibility** | Medium-high. |
| **Confounds** | Life circumstance (remote work, caregiving, recent move); collectivist vs individualist norms; disclosure norms by gender. |

## A5 · Antagonism

| | |
|---|---|
| **Definition** | Disposition to pursue one's own interest at others' expense, and to meet friction with force. |
| **Poles** | Accommodating ←→ Combative |
| **Facets** | **Retaliation** — escalating when pushed. **Callousness** — low weight on others' costs. **Suspicion** — assuming bad intent. |
| **In scope** | Escalation under provocation; bluntness that lands as cruelty; default attributions about others' motives; willingness to win at a cost. |
| **Out of scope** | Assertiveness (asking for what you want isn't antagonism); irritability from A2; being disagreeable about *ideas*. |
| **Boundary cases** | Fierce only when others are wronged → not A5. Blunt in a culture that prizes directness → check against the norm, not against our raters. Cold and unreachable but not hostile → A4, not A5. |
| **Severity** | Mild: wins arguments too often. Notable: relationships regularly damaged. Extreme: harm to others is routine and untroubling. |
| **Body link** | Serotonin — **weak-moderate** (serotonin function ↔ aggression, r ≈ −.12; strongest in pharmacological challenge). Androgen exposure — **moderate at clinical magnitudes only** (CAH; testosterone therapy), **not** normal-range testosterone, where a 1,000-man RCT found nothing. |
| **State sensitivity** | Low-medium. |
| **Visibility** | **Highest divergence of any scale.** Self-report is least valid here; informants see it clearly. This is the scale that justifies the informant module. |
| **Confounds** | Directness norms; gender-differentiated sanctioning of the same behavior; power position. |

## A6 · Unusual cognition

| | |
|---|---|
| **Definition** | Tendency toward unusual perceptions, associations and beliefs, and to act on them. |
| **Poles** | Conventional ←→ Unusual |
| **Facets** | **Perceptual** — sensing what isn't there or reading significance into noise. **Associative** — links others don't see. **Referential** — the sense that events pertain to oneself. |
| **In scope** | Others' reactions to how the person interprets events; unusual sensory experience; a private framework for interpreting the world. |
| **Out of scope** | **Religious, spiritual and culturally normative belief.** Creativity as skill or output. Openness to art and ideas. |
| **Boundary cases** | Believes in prayer, astrology or spirits within a community that shares this → **not scored**; content is culture, not construct. Same belief held idiosyncratically, without a community, with functional consequence → in scope. Vivid imagination without perceptual anomaly → associative facet only. |
| **Severity** | Mild: makes leaps others find odd. Notable: others comment on the interpretations. Extreme: perceptions others don't share, with functional impact. |
| **Body link** | Dopamine D2 — **strong**. Antipsychotics act by D2 blockade; amphetamine can induce psychosis. The strongest dopamine-to-trait link in this whole research folder. |
| **State sensitivity** | Medium. |
| **Visibility** | Medium. |
| **Confounds** | **Religiosity is the dominant confound** and the reason every item here is DIF-tested before shipping. Also: sleep deprivation, bereavement (hallucinations are common and normal), substance use, English fluency. |
| **Report policy** | `internalOnly` in v1 — highest stigma, hardest wording. Feeds interaction rules; not shown as a percentile. |

## A7 · Systemizing

| | |
|---|---|
| **Definition** | Preference for deriving rules and structure over reading people and context, together with heightened sensitivity to detail and change. |
| **Poles** | Fluid/social ←→ Systematic/literal |
| **Facets** | **Rule-seeking** — needing the mechanism before acting. **Detail/change sensitivity** — noticing alterations others miss. **Literality** — taking and giving language at face value. |
| **In scope** | Needing to know how something works; distress at unannounced change; noticing small alterations; missing implication in conversation; sensory load. |
| **Out of scope** | Intelligence; Conscientiousness; Detachment (A4 is about *wanting* closeness, A7 about *reading* people); Unusual cognition. |
| **Boundary cases** | Reads people well *by* system, with effort → counts (the mechanism is systematizing). Loves order for calm, not for mechanism → likely A3, not A7. Detail sensitivity from anxiety → A2. |
| **Severity** | Mild: prefers explicit instructions. Notable: unannounced change derails the day. Extreme: sustained difficulty across social and sensory demands. |
| **Body link** | Highly heritable, polygenic — **genetic, not chemical**. No clean transmitter story, and saying so is part of the point. |
| **State sensitivity** | Low — the most stable scale. Use it as the retest benchmark. |
| **Visibility** | Medium-high. |
| **Confounds** | Occupation (engineers self-select); camouflaging, which is learned and gendered, so self-report understates it in some groups; late diagnosis effects. |

## A8 · Episodicity (short scale, 4 items)

| | |
|---|---|
| **Definition** | Degree to which energy, confidence and output arrive in distinct phases rather than at a steady level. |
| **Poles** | Steady ←→ Cycling |
| **In scope** | Weeks of reduced sleep need with raised output; discrete phases others notice; crashes following peaks; self-described "waves". |
| **Out of scope** | Reactive mood swings within a day (A2); seasonal-only variation (record separately); variation driven by external workload. |
| **Boundary cases** | Cycles with the menstrual cycle → routes to the Block C hormone flag, not A8. Peaks only under deadline → external, not A8. Reduced sleep *need* (not insomnia) is the discriminating feature — write items around it. |
| **Severity** | Mild: productive spells. Notable: distinct phases with a crash. Extreme: phases with decisions later regretted. |
| **Body link** | No direct transmitter claim. The justification is predictive: the Hypomanic Personality Scale was the single best predictor of later bipolar disorder over 23 years (d = 0.67). |
| **State sensitivity** | Medium. |
| **Visibility** | High — others notice phases. |
| **Confounds** | Shift work; seasonal change; substance use; caregiving cycles. |
| **Use** | Modifier, not a headline. High A1 + low A3 + high A8 + impairment is the pre-specified interaction that suggests assessment. |

---

## A9 · Impairment (5 items)

| | |
|---|---|
| **Definition** | How much current functioning is affected, whatever the cause. |
| **Poles** | Unaffected ←→ Severely affected |
| **In scope** | Work/study, relationships, self-care, avoidance, and the one risk item. |
| **Out of scope** | Any attribution of cause. This scale deliberately doesn't ask *why*. |
| **Boundary cases** | Impairment from a physical illness or external crisis → still scored; that's the point, and it's what drives the "look elsewhere" cell. |
| **Severity** | Uses the instrument's own 0–8 anchors rather than our bands. |
| **Body link** | None, declared explicitly. |
| **State sensitivity** | By definition maximal — this *is* the state measure. |
| **Visibility** | Medium. |
| **Confounds** | Life circumstance; stoicism; recency of the crisis. |
| **Use** | **The most important scale in the test.** Crossed with every other scale to separate "a real feature of how you're built" from "this is costing you," and to catch high impairment with an unremarkable profile. |

# Blueprint (Phase 1)

Items per cell, per scale. Generate 3× the final count, keep the keying balanced *within* each severity band so reverse items aren't all clustered at the mild end.

| Scale | Facets | Final items | Generate | Mild / Moderate / Extreme | + / − |
|---|---|---|---|---|---|
| A1 Drive | 2 | 8 | 24 | 3 / 3 / 2 | 4 / 4 |

| **Block A total** | | **65** | **194** | | |

Notes on the grid:
- **A6 gets 28** generated because attrition at the bias gate will be highest there.
- **A9 is all positively keyed** — reversing impairment items confuses respondents and is not standard practice for this format.
- **Extreme-severity items are the scarce resource.** They're hard to write without sounding lurid, and they're what gives the test information at the high end. Two per scale is a floor, not a target.
- Every item gets its informant paraphrase written at generation time, preserving severity.

Blocks B and C are blueprinted separately once Block A clears the review gates.
